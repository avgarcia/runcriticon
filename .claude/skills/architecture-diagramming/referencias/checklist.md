# Lista de validación

- [ ] **Título y metadatos**: ¿Está claro _qué_ es esto y _cuándo_ se creó?
- [ ] **Leyenda**: ¿Puede un desconocido entender cada forma/color?
- [ ] **Consistencia del alcance**: ¿Se mantiene en un solo nivel (Contexto/Contenedor)?
- [ ] **Flujo de datos**: ¿Está clara la dirección? (Solicitud vs Respuesta)
- [ ] **Etiquetas**: ¿Las flechas están etiquetadas con verbos? (p. ej., "envía email" en vez de "email")
- [ ] **Tecnología**: ¿Se listan protocolos/tecnologías donde procede? (JSON/HTTPS, TCP)
- [ ] **Sistemas externos**: ¿Están claramente diferenciados de los internos?
- [ ] **Seguridad**: ¿Son visibles los límites (firewalls, VPCs, autenticación)?
