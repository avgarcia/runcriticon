## Reglas mínimas

- **Anonimizar**: usar iniciales, no nombres completos ni datos identificativos.
- **Pedir consentimiento** para grabar al inicio. Sin grabación si la persona no quiere.
- **Escuchar, no vender**: no se promete nada ni se enseña el producto que se quiere construir hasta el final, y solo si surge.
- **Citas literales** mejor que paráfrasis cuando sea posible.
