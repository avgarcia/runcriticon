# Club Atletismo Local — Coordinador de club

> Persona **post-MVP**. Se mantiene en discovery para no perder visibilidad, pero no condiciona la primera versión.

## Perfil

- Coordinador o director técnico de un club amateur.
- Tiene 3-10 entrenadores y 30-150 atletas.
- Mezcla figura administrativa y técnica.

## Necesidades principales

1. Dar de alta entrenadores y atletas del club.
2. Asignar cada atleta a un entrenador.
3. Vista agregada: cuánto entrenan, asistencia, lesiones, próximas carreras.
4. Decidir un mismo plan base para grupos del club (e.g. grupo de iniciación).

## Frustraciones actuales

- Cada entrenador trabaja por su lado, no hay vista de club.
- Las altas de socios y la información técnica viven en sistemas distintos.

## Por qué es post-MVP

- Aumenta mucho el modelo de permisos y datos.
- Validar primero el flujo entrenador-corredor (1 a N).
- Cuando entren clubs, el flujo principal ya debe estar pulido.
