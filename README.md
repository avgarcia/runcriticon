# Runcriticon

Aplicación para **gestionar entrenos de running**: los entrenadores crean planes personalizados y los asignan a sus corredores; los corredores siguen el plan día a día, registran lo ejecutado y reciben feedback.

> Estado actual: **fase de discovery**. Aún no hay código. La documentación de esta carpeta `docs/` se irá rellenando durante las 2 semanas de descubrimiento del producto.

## Estructura de la documentación

- [`docs/vision.md`](docs/vision.md) — visión y objetivos de negocio.
- [`docs/personas/`](docs/personas/) — fichas de los usuarios objetivo.
- [`docs/research/`](docs/research/) — guion y notas de entrevistas.
- [`docs/journeys/coach-runner.md`](docs/journeys/coach-runner.md) — user journey del flujo entrenador ↔ corredor.
- [`docs/backlog.md`](docs/backlog.md) — funcionalidades priorizadas (MoSCoW).
